# Aloft — архитектурная модель

Текущая версия: **V04, исправления по замечаниям инженера**.

[Скачать Blender V04 — ZIP](Aloft_Blender_v04.zip). Распакуйте архив и откройте `Aloft_v04/Aloft_visual_v04.blend` в Blender 4.3 или новее. Внутри также GLB, изображения, отчёты, перечень допущений и скрипт повторной сборки. Внешние текстуры не требуются.

Исправления V04:

1. Нижняя протяжённая терраса перенесена к первому уровню/входу, предварительно ±0.000 модели. Удалено ограждение над входным козырьком; козырёк сохранён.
2. Под правым оранжевым обрамлением балконы оставлены только в двух верхних рядах; ниже восстановлены исходные оконные проёмы CAD без балконных площадок и ограждений.
3. Исправлено опирание профилей колонн верхней террасы: низ соприкасается с площадкой/поверхностью здания, верх — с нижней гранью кровли. Расширение площадки вокруг наружных профилей предварительное.
4. По скриншоту удалено остекление в красной зоне уступа; расширен витраж в синей зоне основного торца. Обработаны обе поверхности поворота стены. Ширина витража подобрана визуально по разметке.

Последнее указание инженера о первом уровне террасы имеет приоритет над её прежним расположением на JPG. Поэтому совпадение с исходным рендером в этой зоне не является целью проверки.

Сохранён Г-образный план из `Геометрия.dwg`. Исходные DWG не изменены. Глубины/толщины без однозначных размеров предварительные, как разрешил инженер. Полное совпадение остальных частей со всеми шестью рендерами пока не подтверждено. RAL и участок предварительные; электрическая схема, световые сценарии и фотометрия этой выдачей не проверялись.

Проверены повторное открытие BLEND, реимпорт GLB, замкнутость основной оболочки, открытая выемка и четыре группы исправлений. Эти проверки относятся к модели, не являются конструктивным расчётом.
