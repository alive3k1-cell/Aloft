# Aloft — архитектурная модель

Текущая версия: **V03, архитектурная визуализация с отмеченными допущениями**.

[Скачать Blender V03 — ZIP](Aloft_Blender_v03.zip). Распакуйте архив и откройте `Aloft_v03/Aloft_visual_v03.blend` в Blender 4.3 или новее. Внутри также GLB, изображения, отчёты, перечень допущений и скрипт повторной сборки из готовой геометрии. Внешние текстуры не требуются.

Сохранён Г-образный план из `Геометрия.dwg`. Добавлены объёмные терракотовые обрамления, балконные ниши и ограждения, утопленное остекление, откосы и переплёты, кровля с проёмом террасы и опорами, вход и материалы по архитектурным JPG. Логотип восстановлен из контуров DWG; статус официального бренд-файла не проверен.

Инженер разрешил подбирать глубины и толщины без однозначных CAD-размеров по рендерам. Такие размеры, часть окон задних стен балконов и детали нижних уровней предварительные. Цвета не являются утверждёнными RAL; участок условный. Полное совпадение всех шести исходных рендеров и фотореалистичное окружение пока не достигнуты. Электрическая схема, световые сценарии и фотометрия этой выдачей не подтверждаются.

Проверены повторное открытие BLEND, реимпорт GLB, замкнутость основной оболочки и открытая выемка между крыльями. Исходные DWG не изменены.
