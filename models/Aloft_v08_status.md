# Aloft V08 — световые сцены и движение

Откройте `Aloft_light_show_v08.blend` в Blender 4.3+. Архитектура и кровля из V07 сохранены без изменений. Световые линии стоят на прежних координатах DWG; новых соединений через разрывы нет. 61 исходная линия сохранена скрытыми направляющими, видимый диффузор получил 1834 условных пикселя просмотра.

## Запустить

1. Включите Rendered в окне 3D Viewport, Num0 — вид камеры.
2. Нажмите Space над Timeline или 3D Viewport. Кадры 1…192 образуют цикл 8 секунд при 24 кадрах/с. Скорость предпросмотра зависит от компьютера. Сцена стартует в режиме волны.
3. В Outliner выберите `LIGHT_CONTROLS`, затем Object Properties → Custom Properties. `MODE`: 0 — статичный вариант с примера, 1 — плавная смена цвета, 2 — волна, 3 — бегущий свет. Режим меняется сразу, без перезапуска скрипта.

Параметры:

- `MASTER` — общая яркость, 0 выключает неон и связанный локальный свет.
- `SPEED` — скорость движения, 1 означает цикл 8 секунд. Для целого `SPEED` границы диапазона Timeline совпадают; при дробной скорости для бесшовного цикла увеличьте диапазон либо выберите целую скорость.
- `COLOR_AMOUNT` — глубина смены цвета; 0 оставляет цвета примера.
- `WAVE_DEPTH` — глубина волны яркости, 0 делает её постоянной.
- `CHASE_WIDTH` — ширина мягкого бегущего пятна, доля длины контура.
- `ROOF_…`, `BIG_FRAME_…`, `UPPER_FRAME_…`, `POOL_…`: независимые R, G, B, W и LEVEL для каждой группы.
- `POOL_EFFECTS` — 0 сохраняет постоянный свет бассейна, 1 включает его в эффекты. В исходном состоянии бассейн светит мягким нейтральным белым; его линия закреплена на нижней стороне кровли и направлена вниз.
- `ENVIRONMENT`, `DAYLIGHT`, `EXPOSURE`, `BLOOM`, `SPILL` — отдельные настройки окружения, дня, экспозиции, свечения и отражённого света.

RGB меняет оттенок, W добавляется отдельно после цветовых эффектов и остаётся нейтральным. Для статичного белого поставьте R=G=B=0, W=1, MODE=0. Это визуальный белый, без утверждённой цветовой температуры.

Готовые наборы можно включить также через Scripting → Text Editor → `LIGHT_PRESETS.py`: измените PRESET на REFERENCE / WAVE / CHASE / COLOR_FADE / WHITE / POOL / OFF / DAY и нажмите Run Script. Автозапуск Python, дополнения и обработчики кадров не нужны: движение реализовано стандартными узлами материалов и простыми драйверами Blender.

`REFERENCE` возвращает неподвижные цвета принятого примера и выключает бассейн, как V07. `POOL` включает только белый свет бассейна и условную принимающую поверхность; реальная чаша не моделировалась. Остальные режимы скрывают эту тестовую поверхность.

## Содержимое

`light_wave_v08.mp4` — короткий циклический просмотр волны. `reference.png`, `wave.png`, `chase.png` — кадры режимов. `effect_pixel_map.json/csv` — исходные идентификаторы, координаты и геометрическая фаза эффекта. Фаза проходит по контуру для визуализации и не задаёт фактическое направление сигнала, адрес или порт контроллера.

В коротком видео фон рассчитан один раз, а движущиеся диффузоры отрендерены с геометрическим перекрытием зданием и окружением. Это ускоряет просмотр; движущиеся отражения в стекле и отдельный световой след каждого пикселя видео не показывает. Кадры PNG и сама сцена BLEND используют полный рендер сцены. Видео содержит 8 уникальных кадров/с; файл закодирован в 24 кадра/с с повторением кадров.

Гибкий неон: подтверждённые пользователем RGBW, 48 В, 20 Вт/м, 6 пикселей/м; шаг резки около 166,7 мм. Длины по CAD: кровля 138,0035 м; большая рама 98,6401 м; верхняя 40,0008 м; бассейн 29,0300 м; всего 305,6744 м. 1834 точки получены предварительным округлением каждого участка; это не утверждённый раскрой. Пространственное перемешивание цвета внутри реального рассеивателя не рассчитывалось.

Яркости художественные. 11 существующих групповых источников отражённого света в движущихся режимах приглушены до 55%; они не воспроизводят отдельный световой след каждого пикселя. Здесь нет светотехнического расчёта освещённости или готовой программы для оборудования. Внешние текстуры не требуются. Статический GLB из V07 приложен для обмена геометрией; эффекты доступны в BLEND.

В `validation_v08.json` — результаты проверки неизменности архитектуры, исходных линий, идентификаторов и управляющих параметров. Скрипт сборки и исходный BLEND V07 включены в `rebuild` для повторной сборки.
