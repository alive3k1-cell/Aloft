# Aloft — интерактивная световая мастерская V11

Готовый просмотрщик: **[скачать один HTML-файл](https://github.com/alive3k1-cell/Aloft/raw/refs/heads/main/models/Aloft_Interactive_v11.html)**. Сохраните файл и откройте его в актуальном Chrome или Edge. Модель, код и шесть референсов встроены; Blender, установка пакетов и интернет при просмотре не нужны. Используется WebGL2 и видеокарта браузера.

Панель содержит:

- восемь ракурсов, шесть камер исходных референсов и сохранение своего ракурса;
- вращение мышью, масштабирование колесом, сдвиг ПКМ и прогулку вокруг здания — WASD/стрелки, Shift для ускорения, Esc для отпускания мыши;
- день/ночь, время суток и экспозицию;
- три качества просмотра, полноэкранный режим и сохранение PNG;
- варианты палитры и сценарии: исходный, волна, бегущий свет, смена цвета, DOTS 06 с лаймом и мятой, программа 30 с;
- отдельные RGB, W, яркость и включение четырёх групп; независимые эффекты бассейна, общую яркость и свечение;
- паузу, скорость, сохранение настроек в браузере и перенос настроек через JSON.

Температура белого в 2700…6500 K — предварительная визуальная настройка; CCT установленного неона не подтверждена. Время суток управляет художественным небом, без привязки к северу, точному адресу и расчёта положения солнца. DOTS 06 адаптирован к существующим линиям проекта: светодиодная матрица на стенах не добавлялась.

V11 исправляет только отмеченные пользователем места: тёмный серый керамогранит, чёрную кровлю с открытым проёмом над бассейном, стыки ламелей, террасу второго этажа и видимость неона у крыши. Ночное окружение существенно приглушено; дневное освещение и настройки RGBW сохранены. В модели 94 архитектурных объекта. 62 исходных объекта вне исправляемой кровли сохранены с идентичной геометрией.

Все 61 исходные линии DWG, их длины и 1834 точки эффекта сохранены. Для закрытия коротких разрывов и уступа во дворе добавлены 4 визуальные перемычки общей длиной 2,4301 м; они отмечены отдельно и не включены в исходную CAD-ведомость. Высота установки кровельного неона уточнена по новой подшивке. Исходные DWG и V08 BLEND не изменены; исправления сохранены в отдельном V11 BLEND. `assets/scene.json` содержит камеры и установочные линии; `assets/aloft_v11.glb` — геометрию с фазой эффекта в UV.

Это браузерная PBR-визуализация Three.js, её изображение отличается от Cycles. Быстрый режим сокращает постобработку; баланс использует сглаживание, тени, Bloom и укрупнённый отражённый свет; Cinematic добавляет GTAO, MSAA×4 при поддержке GPU, более высокое разрешение, физическое пропускание стекла и дополнительные источники отражённого света. Для слабого компьютера выбирайте «Быстро». Отражённый свет групповой и художественный; IES-профили, светотехнический расчёт и подключение контроллеров здесь не реализованы.

## Сборка из исходников

Node.js 22+:

```sh
cd viewer
npm ci
npm run build
npm start
```

Откройте `http://127.0.0.1:8080`. `dist/index.html` — готовый автономный файл. Геометрия уже включена, для сборки Blender не требуется. Для пересборки геометрии нужны рабочие материалы V07/V08 в папке `ALMAZOV_WORKDIR`: сначала `tools/prepare_revision_v11.py` (NumPy и Shapely 2.1+), затем в Blender `tools/apply_revision_v11.py` и `tools/export_blender.py`. Скрипт правок сохраняет отдельный V11 BLEND и проверяет неизменность остальной геометрии.

Дополнительно: `python tests/revision-v11.py` проверяет связность неона, положение экспортированных трубок, проём кровли и неизменность исходного BLEND; `node tests/review-v11.mjs after` сохраняет контрольные виды.

Проверки: `node tests/state.mjs`; при запущенном локальном сервере — `node tests/browser.mjs`. Браузерные проверки используют Chromium и Playwright, путь можно передать через `CHROMIUM_PATH`. Результаты и снимки сохраняются в `test-output`.

Three.js распространяется по MIT; полный текст лицензии включён в готовый HTML и `THIRD_PARTY.md`.
