# Aloft — интерактивная световая мастерская V10

Готовый просмотрщик: **[скачать один HTML-файл](https://github.com/alive3k1-cell/Aloft/raw/refs/heads/main/models/Aloft_Interactive_v10.html)**. Сохраните файл и откройте его в актуальном Chrome или Edge. Модель, код и шесть референсов встроены; Blender, установка пакетов и интернет при просмотре не нужны. Используется WebGL2 и видеокарта браузера.

Панель содержит:

- восемь ракурсов, шесть камер исходных референсов и сохранение своего ракурса;
- вращение мышью, масштабирование колесом, сдвиг ПКМ и прогулку вокруг здания — WASD/стрелки, Shift для ускорения, Esc для отпускания мыши;
- день/ночь, время суток и экспозицию;
- три качества просмотра, полноэкранный режим и сохранение PNG;
- варианты палитры и сценарии: исходный, волна, бегущий свет, смена цвета, DOTS 06 с лаймом и мятой, программа 30 с;
- отдельные RGB, W, яркость и включение четырёх групп; независимые эффекты бассейна, общую яркость и свечение;
- паузу, скорость, сохранение настроек в браузере и перенос настроек через JSON.

Температура белого в 2700…6500 K — предварительная визуальная настройка; CCT установленного неона не подтверждена. Время суток управляет художественным небом, без привязки к северу, точному адресу и расчёта положения солнца. DOTS 06 адаптирован к существующим линиям проекта: светодиодная матрица на стенах не добавлялась.

В основе принятая модель V08: 92 архитектурных объекта, 61 исходный световой участок и 1834 условных пикселя просмотра. Исходные DWG и BLEND не изменены. `assets/scene.json` содержит контрольные суммы, камеры и привязку линий; `assets/aloft_v10.glb` — переносимую геометрию с фазой эффекта в UV.

Это браузерная PBR-визуализация Three.js, её изображение отличается от Cycles. Быстрый режим сокращает постобработку; баланс использует сглаживание, тени, Bloom и укрупнённый отражённый свет; Cinematic добавляет GTAO, MSAA×4 при поддержке GPU, более высокое разрешение, физическое пропускание стекла и дополнительные источники отражённого света. Для слабого компьютера выбирайте «Быстро». Отражённый свет групповой и художественный; IES-профили, светотехнический расчёт и подключение контроллеров здесь не реализованы.

## Сборка из исходников

Node.js 22+:

```sh
cd viewer
npm ci
npm run build
npm start
```

Откройте `http://127.0.0.1:8080`. `dist/index.html` — готовый автономный файл. Геометрия уже включена, для сборки Blender не требуется. Экспорт из рабочего BLEND выполняет `tools/export_blender.py`; ему нужны рабочие материалы V07/V08 в папке `ALMAZOV_WORKDIR`.

Проверки: `node tests/state.mjs`; при запущенном локальном сервере — `node tests/browser.mjs`. Браузерные проверки используют Chromium и Playwright, путь можно передать через `CHROMIUM_PATH`. Результаты и снимки сохраняются в `test-output`.

Three.js распространяется по MIT; полный текст лицензии включён в готовый HTML и `THIRD_PARTY.md`.
