# Aloft — интерактивная световая мастерская V12

Готовый просмотрщик: **[скачать один HTML-файл](https://github.com/alive3k1-cell/Aloft/raw/refs/heads/main/models/Aloft_Interactive_v12.html)**. Сохраните файл и откройте его в актуальном Chrome или Edge. Модель, код и шесть референсов встроены; Blender, установка пакетов и интернет при просмотре не нужны. Используется WebGL2 и видеокарта браузера.

Панель содержит:

- восемь ракурсов, шесть камер исходных референсов и сохранение своего ракурса;
- вращение мышью, масштабирование колесом, сдвиг ПКМ и прогулку вокруг здания — WASD/стрелки, Shift для ускорения, Esc для отпускания мыши;
- день/ночь, время суток и экспозицию;
- три качества просмотра, полноэкранный режим и сохранение PNG;
- варианты палитры и сценарии: исходный, волна, бегущий свет, смена цвета, DOTS 06 с лаймом и мятой, программа 30 с;
- отдельные RGB, W, яркость и включение четырёх групп; независимые эффекты бассейна, общую яркость и свечение;
- паузу, скорость, сохранение настроек в браузере и перенос настроек через JSON.

Температура белого в 2700…6500 K — предварительная визуальная настройка; CCT установленного неона не подтверждена. Время суток управляет художественным небом, без привязки к северу, точному адресу и расчёта положения солнца. DOTS 06 адаптирован к существующим линиям проекта: светодиодная матрица на стенах не добавлялась.

V12 сохраняет принятую архитектуру V11. Убрано только нижнее стеклянное ограждение первого этажа вместе с его рамками. Остальные 90 архитектурных объектов сохранены: проверены геометрия, трансформации и назначения материалов. Все 65 видимых линий неона (61 исходная и 4 визуальные перемычки), их анимация и 1834 исходные точки эффекта не изменены.

После18:35 сумерки продолжаются плавно, полный ночной режим имеет умеренный фоновый свет. Дневные значения сохранены. Перекрытие вспомогательной подсветки стенами рассчитано по непрозрачной архитектуре: по5 проб вдоль каждого из11 линейных источников. Результат хранится в дополнительных атрибутах GLB и интерполируется по поверхности. Эти источники дают только рассеянный свет; ложные зеркальные блики от них исключены. Положение вершин, индексы и материалы всех оставшихся GLB-мешей идентичны V11. Это приближение для неподвижной модели; IES/фотометрия и расчёт оборудования не добавлены.

`assets/scene.json` содержит камеры, световые линии и параметры проверки видимости; `assets/aloft_v12.glb` — текущую переносимую геометрию. Исходные DWG и старые BLEND/HTML сохранены отдельно.

Это браузерная PBR-визуализация Three.js, её изображение отличается от Cycles. Быстрый режим сокращает постобработку; баланс использует сглаживание, тени, Bloom и укрупнённый отражённый свет; Cinematic добавляет GTAO, MSAA×4 при поддержке GPU, более высокое разрешение, физическое пропускание стекла и дополнительные источники отражённого света. Для слабого компьютера выбирайте «Быстро». Отражённый свет групповой и художественный; IES-профили, светотехнический расчёт и подключение контроллеров здесь не реализованы.

## Сборка из исходников

Node.js 22+:

```sh
cd viewer
npm ci
npm run build
npm start
```

Откройте `http://127.0.0.1:8080`. `dist/index.html` — готовый автономный файл. Геометрия уже включена, для сборки Blender не требуется. Для пересборки геометрии нужны рабочие материалы V07/V11 в папке `ALMAZOV_WORKDIR`: в Blender последовательно выполните `tools/apply_revision_v12.py`, `tools/export_blender.py`, `tools/bake_spill_visibility_v12.py`. Последний скрипт запускается один раз на свежем экспорте GLB и добавляет атрибуты перекрытия света, сохраняя позиции/индексы/материалы. Далее выполните `npm run build`.

Дополнительно: в Blender `tools/verify_revision_v12.py` сравнивает все262 сохранённых объекта мешей/кривых с V11; `python tests/revision-v12.py` проверяет174 сохранённых GLB-меша, непрозрачность твёрдых материалов и блокирование света в контрольных точках. `node tests/review-v12.mjs` снимает сумерки18:35, ночь, крышу в двух режимах и нижнюю террасу.

Проверки: `node tests/state.mjs`; при запущенном локальном сервере — `node tests/browser.mjs`. Браузерные проверки используют Chromium и Playwright, путь можно передать через `CHROMIUM_PATH`. Результаты и снимки сохраняются в `test-output`.

Three.js распространяется по MIT; полный текст лицензии включён в готовый HTML и `THIRD_PARTY.md`.
